# Home Twin development

Private home knowledge lives in the user's Fulcra account, outside this repository. Keep public examples synthetic. Preserve source evidence, file versions and contribution identities. Never infer service completion, a maintenance interval, exact geometry or a live device state from missing evidence.

Use the configured workstream record and owned task bus for the current deployment. At each turn's exit, read its current next actions and this agent's accepted assignments. Continue safe authorized unblocked work; record concrete prerequisites and resume steps for blocked work. Preserve peers' ownership. A coordination outage does not block independent local work.

Shared-home reads use the caller's Fulcra token and current permissions. All writes belong to that caller's account. Do not bypass membership, borrow an owner's token, or share unrelated vault data to simplify collaboration. One designated maintainer updates accepted snapshots.

Test data contracts and contribution behavior before changing production code. Verify deployed user workflows before completion claims. Keep per-run evidence in the deployment's private Fulcra workspace; it does not belong in public fixtures.
